# Initiative or Product Title
## Overview
This is the Initiative or product document. This file describes the repository, the goal of the software being built, and the users it's serving. This section gives an overview of the product. In Linear, this is referred to as an "Initiative".

## Problem
This section describes the pain that exists today, who feels it, and why it's worth solving now.

## Goals
This section describes the goals of the repository. Each goal is an outcome tied to the Problem.

## Users
This section describes the users that this piece of software is serving.

## Features
This gives an overview of the features of the software. Each area of the product links to its project file, e.g. [Project Title](projects/projectTitle/projectTitle.md). A feature that no project has claimed yet is listed as a plain bullet until a project claims it.

## Links
This section links to the Initiative in the project management tool (like Linear), the team that owns it, and each of its projects. It's only included when the Initiative has been pushed to the project management tool.
