# Project Title
This is an overview of the project within the application; usually, this is a product section or feature set. In Linear, this is referred to as a "Project".

## Owners
This section lists the people accountable for this project, marking one of them as the lead.

## Goal
This describes the goal of this area of the product. This goal is connected directly to the users and the problems they need solved.

## Users
This section lists which of the Initiative's users this project serves, and what it gives each of them.

## Scope
This section describes what's in scope for this project, and what's out of scope (left to other projects or to later).

## Milestones
This section lists the checkpoints on the way to the Goal, each with what's true once it's reached and an optional target date. In Linear, these are the project's milestones.

## Features
This section contains detailed listings of all the features that are part of this project and already exist in the product.

### Feature Title
This is a description of the feature in detail. It contains details of what's actually in product.

## Planned features
This section lists features that haven't been built yet. When a dev cycle ships one, it moves up to Features.

### Feature Title
This is a description of what the feature will let users do, and which milestone delivers it.

## Links
This section links to the project in the project management tool (like Linear). It's only included when the project has been pushed to the project management tool.

This is a description of the change, update, or feature that was implemented. This is a very brief overview of the software development cycle that connects to this product section.
